基于 AGENT.template.md v4.0 的项目生命周期治理模板，用于初始化 AGENTS.md、OPINION.md、AGENT.RULES.md 与过程文档。

资源入口

AI 原文 执行入口与初始化流程，适合 Agent 直接读取。 机器元数据 版本、路径、标签、输入输出等结构化信息。 模板文件 初始化时读取的完整治理模板与知识库。

文件分工

文件 作用
SKILL.mdAI Agent 的执行入口，说明触发方式、流程和必读文件。
AGENT.template.md完整治理模板，项目初始化时作为母版读取。
skill.json机器可读元数据，用于索引、安装、版本检查和自动发现。
index.html浏览器可读页面。

适用场景

  • 新仓库需要建立 AI 协作规则。
  • 旧仓库需要把零散口头约定沉淀为可执行规范。
  • 多个 Agent、编辑器或自动化工具需要共享同一份项目上下文。
  • 团队希望减少重复说明、风格漂移和错误假设。

输入信息

字段 必填 说明
项目名称是仓库或产品的名称。
项目目标是一句话说明项目要解决的问题。
技术栈是语言、框架、包管理器、数据库、部署方式。
运行方式是本地启动、测试、构建、部署命令。
协作偏好是语言、输出结构、是否先问再写代码。
质量门禁是测试、Lint、格式化、审查规则。

标准流程

  1. 扫描项目结构、配置文件、脚本和现有文档。
  2. 区分已确认事实、合理推断和待确认假设。
  3. 只对影响执行质量的问题提问。
  4. 生成结构完整的 AGENTS.md 草案。
  5. 确认项目目标、协作偏好、质量门禁和禁止事项。
  6. 写入仓库根目录并用一次小任务验证可用性。
